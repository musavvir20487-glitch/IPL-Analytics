# 🏏 IPL Analytics Project

End-to-end data analytics project on IPL (2008–2022) using Python, SQL, and MySQL.

## 📌 Project Overview
Analyzed 900+ IPL matches to uncover insights on team performance, 
top players, toss impact, and season trends.

## 🛠️ Tech Stack
- Python (pandas, matplotlib, seaborn)
- MySQL + mysql-connector-python
- Jupyter Notebook

## 📁 Project Structure
- `data/` — Raw CSV datasets (matches, deliveries)
- `sql/` — SQL queries for analysis
- `python/` — Data cleaning, SQL analysis, visualizations
- `charts/` — 6 saved visualization charts

## 📊 Key Analyses
- Most wins by team across all seasons
- Top run scorers and best bowlers
- Toss decision impact on match results
- Season-wise runs trend
- Win probability heatmap

## 🚀 How to Run
1. Clone the repo
2. Install requirements: `pip install pandas matplotlib seaborn mysql-connector-python`
3. Run `ipl_analysis.ipynb` in Jupyter
